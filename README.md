# منصة إعمار وبنيان

منصة MVP متكاملة لتمويل مشاريع البنية التحتية.

المحتوى المتاح:
- `index.html`: واجهة المستخدم الرئيسية مع دعم الأدوار الثلاثة.
- `style.css`: تصميم حديث مع وضع ليلي ونهاري.
- `app.js`: منطق التفاعل، خريطة Leaflet، تقدم التمويل، ونظام محفظة التأمين.
- `server.js`: خادم Node.js محلي لخدمة ملفات التطبيق وبيئة تشغيل التطوير.
- `package.json`: سكريبتات جاهزة للتشغيل والتحقق.
- `.env.example`: إعدادات البريد الإلكتروني السابقة الموجودة كمثال.

كيفية التشغيل:
1. إذا لم يكن لديك Node.js، ثبّته من https://nodejs.org.
2. افتح سطر الأوامر داخل مجلد المشروع.
3. شغل `npm install` لتثبيت الاعتمادات.
4. شغّل `npm start` لبدء الخادم المحلي.
5. افتح المتصفح وزر `http://localhost:3000`.

تأكد من عمل المشروع:
- `npm run check` للتحقق من صحة الخادم المحلي `server.js`.

تسجيل وحسابات البريد الإلكتروني:
- يتم الآن إدارة المستخدمين بواسطة Firebase Authentication.
- عند إنشاء حساب، يُرسل Firebase رابط تأكيد إلى البريد الإلكتروني.
- يجب تأكيد البريد قبل تسجيل الدخول.
- تسجيل الدخول والتأكد من الدور يتمان من خلال Firebase Realtime Database.

ملاحظة:
- `.env.example` موجود فقط كمرجع لإعدادات البريد السابقة، ولا يلزم إعداد SMTP لتشغيل نظام التسجيل الجديد.

كيفية الاستخدام:
1. افتح `http://localhost:3000` بعد تشغيل الخادم.
2. استخدم صفحة التسجيل لإنشاء حساب جديد باستخدام بريدك الإلكتروني.
3. تحقق من رسالة التأكيد في بريدك أو في رابط معاينة البريد المحلي.
4. بعد التأكيد، سجّل الدخول باستخدام البريد وكلمة المرور.
5. ستظهر لك الواجهة المناسبة حسب الدور:
   - المواطن: إضافة بلاغات وموقع.
   - المتبرع: تصفح المشاريع وخريطة التمويل.
   - المقاول: عرض الضمانات وإدارة المشاريع.

نشر على Google AI Studio:
1. أنشئ صورة Docker:
   - `docker build -t vip-vxr .`
2. ادفع الصورة إلى سجل الحاويات المدعوم من Google (Container Registry أو Artifact Registry).
3. في AI Studio، استخدم خيار نشر تطبيق أو حاوية مخصصة وحدد الصورة التي بنيتها.
4. تأكد من أن التطبيق يستمع على المنفذ `3000` ويدعم المسار الجذري `/`.
5. عند فتح التطبيق، سترى رسالة تأكيد في واجهة المستخدم تقول إن المشروع جاهز للتشغيل والنشر على AI Studio.

الملفات المضافة للنشر:
- `Dockerfile`: يبني الحاوية لتشغيل التطبيق.
- `.dockerignore`: يقلّل حجم البناء عن طريق تجاهل الملفات غير الضرورية.
