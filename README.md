# منصة إعمار وبنيان

منصة MVP متكاملة لتمويل مشاريع البنية التحتية.

المحتوى المتاح:
- `index.html`: واجهة المستخدم الرئيسية مع دعم الأدوار الثلاثة.
- `style.css`: تصميم حديث مع وضع ليلي ونهاري.
- `app.js`: منطق التفاعل، خريطة Leaflet، تقدم التمويل، ونظام محفظة التأمين.
- `server.js`: خادم محلي بسيط لتشغيل المشروع على `http://localhost:3000`.
- `package.json`: سكريبتات جاهزة للتشغيل والتحقق.

كيفية التشغيل:
1. إذا لم يكن لديك Node.js، ثبّته من https://nodejs.org.
2. افتح سطر الأوامر داخل مجلد المشروع.
3. شغّل `npm start` لبدء الخادم المحلي.
4. افتح المتصفح وزر `http://localhost:3000`.

تأكد من عمل المشروع:
- `npm run check` للتحقق من صحة `app.js`.

كيفية الاستخدام:
1. افتح `http://localhost:3000` بعد تشغيل الخادم.
2. سجّل الدخول باستخدام حساب تجريبي:
   - المواطن: `reporter1` / `reporter123`
   - المتبرع: `investor1` / `investor123`
   - المقاول: `contractor1` / `contractor123`
3. استخدم أزرار الأدوار للتنقل بين واجهة المواطن، المتبرع، والمقاول.
4. في واجهة المواطن، يمكن تقديم بلاغ مع وصف وموقع.
5. في واجهة المتبرع، يمكن مشاهدة المشاريع على الخريطة ومؤشرات التمويل.
6. في واجهة المقاول، يظهر المبلغ المطلوب كضمان محفظة التأمين.
